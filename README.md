# 📇 Business Card - Scrimba HTML & CSS Exercise

Este projeto é parte de um exercício da trilha de HTML e CSS da [Scrimba](https://scrimba.com), onde foi proposto criar um **cartão de visita digital (business card)** utilizando HTML e CSS.

## ✨ Objetivo

Praticar:
- Estruturação semântica com HTML5
- Estilização básica com CSS
- Layout com `flexbox`
- Uso de imagens e classes

## 🛠️ Tecnologias Usadas

- HTML5  
- CSS3

## 🖼️ Preview

<img src="images/perfil-roan.png" width="200" alt="Preview do avatar" />

## 📄 Estrutura

- **index.html**: Contém a estrutura principal do cartão de visita com imagem, nome, cargo e localização.
- **styles.css**: Estilização do componente com foco em alinhamento, cores e tipografia.
